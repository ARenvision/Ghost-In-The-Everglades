# Ghost-In-The-Everglades
A nighttime airboat rescue game set in the Everglades, featuring dynamic return-route closures built with Kiro’s Spec mode for Kiroween 2026.
## Play

[Play Ghost in the Everglades](https://ghost-in-the-everglades.arenvision.chatgpt.site/)

## Run locally

From the project folder, run `python -m http.server 8000 --directory dist`.
Then open [localhost:8000](http://localhost:8000/) in your browser.
